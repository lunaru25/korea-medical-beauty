🔧 如何接入 Naver 真实数据

  1. 前往 developers.naver.com 免费注册并创建应用
  2. 申请 지역(Local) 검색 API 权限
  3. 将 Client ID 和 Secret 填入项目根目录的 .env 文件
  4. 重启服务，数据将自动从 Naver 实时获取并缓存

注：Naver Local API 不含评分数据，如需真实评分可接入 Apify Naver Map Scraper。
